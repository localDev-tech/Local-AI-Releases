Before you start

Local AI talks to Ollama, which is what actually runs the models. The Windows setup installer installs Ollama if needed. For portable, macOS or Linux builds, install Ollama separately. Then download models from inside Local AI.

Windows will show a blue “Windows protected your PC” box, because the app is not code-signed yet. Click More info → Run anyway.

macOS will say the app “cannot be opened because the developer cannot be verified”, for the same reason. Right-click the app → Open → Open, or allow it under System Settings → Privacy & Security.

Linux: the AppImage needs to be made executable before it will run — chmod +x Local-AI-*.AppImage — and it is the version that updates itself. The .deb is installed and updated through your package manager instead.
